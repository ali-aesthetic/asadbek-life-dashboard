# Life Dashboard

> My personal dashboard for one week at a time: gym, study, books, courses, projects and mood.

## What's inside

| Tab | What it tracks |
|:--|:--|
| Dashboard | The week plan, gym progress ring, mood log |
| Courses | Course progress, notes and assignments |
| Books | Reading list, pages read, notes and ratings |
| Projects | Side projects with deadlines and progress |
| Weekly review | A short reflection at the end of the week |

Everything is saved in the browser (localStorage) — no account, no server.

## Built with

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Zustand · Recharts · Framer Motion

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
